# Casa Vazquez AI Agent

AI-powered voice reservation system for my bar Casa Vazquez.

## Goal

The app will assist coordinating reservations by phone using an voice agent.

The voice agent will be able to:

- answer common questions
- check reservation availability
- create reservations
- handle incomplete customer information
- interact with backend services through tools

## Planned Architecture

Voice Agent -> n8n -> FastAPI -> PostgreSQL

Next.js for admin interface
